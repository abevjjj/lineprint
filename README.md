# looprint

一个本地运行的订单清洗和 ESC/POS 打印小工具。

## 功能

- 粘贴原始订单文本并按方案清洗
- 方案清洗代码可仿照其他清洗函数书写
- 选择打印机和标题后直接发送到局域网打印机
- 管理打印机列表、标题库和定时打印任务
- 支持定时任务的首次密码设置与长期登录保持

## 启动方式

1. 安装依赖：

```bash
python3 -m pip install -r requirements.txt
```

2. 启动程序：

```bash
python3 app.py
```

3. 在浏览器中打开：

```text
http://127.0.0.1:5006
```

## 数据库说明

- 数据库文件不会提交到仓库，已加入 `.gitignore`
- 程序会在首次启动时自动创建空数据库
- 当前数据库默认放在 `instance/printer_v4.db`

## 登录说明

- 默认登录密码写在 `app.py` 中的 `ACCESS_PASSWORD`
- 登录后会保持较长时间的会话，不需要每次重新输入

## 注意

- 这是一个本地/内网工具，不建议直接暴露到公网
- 如果要长期部署到服务器，建议把 `secret_key` 和登录密码改成环境变量
